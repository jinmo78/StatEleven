Stat Eleven 개인정보처리방침

시행일: 2026년 11월 10일

Stat Eleven(이하 "서비스")은 브라우저에서 실행되는 축구 매니지먼트 시뮬레이션 게임입니다. 로그인 없이도 플레이할 수 있으며, 이 경우 진행 상황은 이용자 브라우저에만 저장되고 운영자에게 어떠한 개인정보도 전송되지 않습니다.

1. 수집하는 정보

이용자가 선택적으로 구글 계정으로 로그인하여 클라우드 저장 기능을 사용하는 경우에만 아래 정보를 처리합니다.

항목내용
구글 계정 정보이메일 주소, 이름, 프로필 사진 URL, 구글 계정 식별자
게임 저장 데이터구단 정보, 선수·전술·리그 진행 상황 등 게임 내 데이터
자동 생성 정보로그인 시각, 저장 시각 등 인증·저장 처리 기록

2. 이용 목적

  • 로그인한 이용자 본인 확인
  • 게임 진행 상황을 클라우드에 저장하고 다른 기기에서 불러오기

수집한 정보를 광고, 마케팅, 제3자 판매 목적으로 사용하지 않습니다.

3. 보관 및 처리 위탁

로그인 및 데이터 저장은 Supabase(인증·데이터베이스 호스팅)를 통해 처리됩니다. 구글 로그인 과정에는 Google의 인증 서비스가 사용됩니다. 각 사용자의 저장 데이터는 본인만 읽고 쓸 수 있도록 접근이 제한됩니다.

4. 보관 기간 및 삭제

정보는 이용자가 삭제를 요청하거나 서비스가 종료될 때까지 보관합니다. 계정 및 저장 데이터 삭제를 원하시면 아래 문의처로 요청해 주세요. 요청 확인 후 지체 없이 삭제합니다.

5. 브라우저 저장소

서비스는 게임 진행 상황과 로그인 상태 유지를 위해 브라우저의 localStorage를 사용합니다. 브라우저의 사이트 데이터 삭제 기능으로 언제든지 지울 수 있습니다. 추적용 쿠키나 분석 도구는 사용하지 않습니다.
